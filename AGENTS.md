# Agents

- **Asked to install this repository?** Follow [`INSTALL.md`](INSTALL.md).
- **Asked to turn a wiki into a graph?** Use the `wiki-to-graph` skill
  ([`skills/wiki-to-graph/SKILL.md`](skills/wiki-to-graph/SKILL.md)): build, validate, open the
  viewer. Do not ask the user to reformat the wiki first — the build adapts it.
- **Changing the code?** Run `python3 -m unittest discover tests` before and after.
